## Dataset

Dataset yang digunakan dalam penelitian ini diperoleh dari Kaggle:

- **Source:** Kaggle
- **Dataset:** AIML Dataset
- **Link:** [Kaggle Dataset](https://www.kaggle.com/datasets/amanalisiddiqui/fraud-detection-dataset?resource=download)

Karena ukuran dataset cukup besar, file dataset tidak disertakan dalam repository GitHub.

### Dataset Setup

1. Download dataset dari Kaggle.
2. Simpan file `AIML Dataset.csv` di folder utama project.
3. Jalankan notebook atau aplikasi.
